content = """# Cours Git — Version Simplifiée et Complète

## 1. Définition
Git est un système de gestion de versions distribué permettant de suivre l’évolution d’un projet, de collaborer efficacement et de conserver un historique complet des modifications.

## 2. Structure générale
- **Repository (repo)** : dossier contenant le projet et son historique Git.
- **Commit** : capture du code à un instant donné.
- **Branch** : ligne parallèle de développement.
- **HEAD** : pointeur vers la branche ou le commit actif.
- **Remote** : version du repo hébergée en ligne (GitHub, GitLab…)

## 3. Pourquoi utiliser Git ?
- Historique complet
- Travail en équipe sans conflit
- Sauvegarde et restauration
- Expérimentation via les branches
- Déploiement simplifié
